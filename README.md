# Retail Data Analyst Project

## Project Overview
This project focuses on analyzing retail data using Python, SQL, and Power BI. The analysis aims to understand customer characteristics, order patterns, sales performance, and business insights from retail datasets.

## Tools & Technologies
- **Python** – Data cleaning, data processing, and exploratory data analysis (EDA).
- **Pandas** – Data manipulation and analysis.
- **Matplotlib** – Data visualization.
- **MySQL** – Data exploration and SQL-based analysis.
- **Power BI** – Interactive dashboard and data visualization.

## Dataset
This project uses two datasets:

- **Customer Data** – Contains customer information, including age, gender, purchase amount, location, payment method, and purchase frequency.
- **Order Data** – Contains order information, including order date, shipping mode, product category, quantity, price, and discount.

## Project Workflow

### 1. Data Understanding
- Inspecting dataset structure and dimensions.
- Checking data types.
- Identifying missing values and duplicate records.

### 2. Data Cleaning (Python)
- Renaming columns for consistency.
- Converting order dates into datetime format.
- Handling missing values.
- Removing duplicate customer records.
- Checking outliers using boxplots.

### 3. Exploratory Data Analysis (EDA)
- Analyzing customer demographics.
- Exploring purchase behavior.
- Examining order and product distributions.
- Calculating revenue.

### 4. SQL Analysis
Using SQL to explore and analyze retail data, including:
- Data exploration and filtering.
- Key Performance Indicators (KPIs).
- Sales analysis.
- Customer analysis.
- Advanced SQL queries.

### 5. Dashboard Development
Creating a Power BI dashboard to present retail data insights through visualizations and key metrics.

## Project Objective
The objective of this project is to practice data analytics skills through data cleaning, exploratory data analysis, SQL querying, and dashboard development.
